# Hidden-Neuron Analysis of Real and Synthetic Images

This repository contains the **code, analysis notebooks, and data resources** associated with the paper:

**Do CNNs Internally Represent Real and Synthetic Images Differently? A Hidden-Layer Analysis**

The paper will appear at **[NeSy 2026 — International Conference on Neural-Symbolic Learning and Reasoning](https://2026.nesyconf.org/)**.

**Paper:** https://arxiv.org/abs/2608.14729

## Overview

This work investigates whether CNNs exhibit different hidden-layer activation patterns for real and AI-generated images with similar semantic content.
